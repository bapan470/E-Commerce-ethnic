FEATURE — CLICK Sent/Opened/Clicked/Failed TO SEE WHO
========================================================

What this adds
----------------
In Admin -> WooCommerce Import, section "2. Imported customers", the four
summary cards (Sent / Opened / Clicked / Failed) are now clickable —
exactly like the Purchased/Cart abandoners/Wishlist/etc audience chips
right below them. Clicking one opens a popup listing every matching
person: Name, Email, Phone, which campaign (subject), and the date.

  - Sent    -> everyone an email was actually delivered to (any campaign)
  - Opened  -> everyone who opened at least one campaign email
  - Clicked -> everyone who clicked a link inside a campaign email
  - Failed  -> everyone whose send failed

("Open rate" is just a % of the above, so it isn't clickable.)

This uses data you already had (the same woocommerce_campaign_sends table
your existing Sent/Opened/Clicked/Failed counts come from) — no new
database migration needed, no new setup.

How to apply
-------------
Copy these 3 files into your local clone at the same paths (overwriting
the 2 existing ones), then:

    git add app/api/admin/woocommerce-import/send-campaign/recipients/route.ts \
            lib/woocommerce-import-api.ts \
            components/admin/woocommerce-import-panel.tsx
    git commit -m "Add clickable Sent/Opened/Clicked/Failed recipient lists"
    git push
