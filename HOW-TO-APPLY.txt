NAYA KYA HAI IS VERSION ME
---------------------------
- Har banner me ab "Desktop" aur "Mobile" — do alag tabs hain Admin >
  Hero Banners > Add/Edit Banner dialog me. Mobile tab optional hai:
  agar kuch upload nahi karte, phone par bhi desktop wala hi image/
  video dikhega (kuch tootega nahi).
- Mobile ke liye apna image YA video independently choose kar sakte
  ho — matlab desktop par video aur mobile par halka image bhi rakh
  sakte ho, ya dono jagah alag cheez.
- Koi bhi image upload karte hi (desktop ho ya mobile, banner image ho
  ya video ka cover-frame) automatically WebP me convert ho jaata hai
  browser me hi, upload hone se pehle — chhoti file size, fast loading.
  (Video files WebP me convert nahi hoti — wo already compressed
  format hai, wahan koi change nahi.)

STEPS
-----
1. Upar wali 5 code files apne local repo me same path par paste
   karke overwrite kar do.
2. 6th file (migration .sql) supabase/migrations/ folder me copy karo.
3. Supabase par migration apply karo (Dashboard > SQL Editor me paste
   + run, YA `supabase db push` agar CLI use karte ho).
   >>> Migration ke bina Mobile tab dikhega zaroor lekin save karte
       waqt error dega (mobile_image_url column DB me nahi hoga).
4. `git add .`
   `git commit -m "Hero banners: mobile-specific media + auto WebP"`
   `git push`
5. Deploy hone ke baad test karo: Admin > Hero Banners > Add Banner >
   Mobile tab > "Add a mobile-specific banner" > upload > save, phir
   phone (ya Chrome DevTools mobile view) se homepage check karo.
