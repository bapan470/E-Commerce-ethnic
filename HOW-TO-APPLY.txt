Admin Orders me "select karke delete" option
==============================================

Kya add hua
------------
Admin -> Orders panel me ab checkbox se orders select karke ek saath
delete kar sakte ho — header me "select all", har row me checkbox,
selection hote hi "Delete Selected" wala laal bar, aur confirm popup
(galti se delete na ho jaaye isliye).

Files (isi zip me, same path pe)
---------------------------------
  lib/orders-api.ts                        (MODIFIED)
  app/api/admin/orders/route.ts            (MODIFIED)
  components/admin/orders-panel.tsx        (MODIFIED)

Apply kaise karein (Windows)
------------------------------
1. Is zip ko extract karo.
2. Extract karne se jo "app", "components", "lib" folders bane hain,
   unhe seedha apne project folder me copy-paste kar do:
     C:\Users\bapan\E-Commerce-ethnic\
   Windows puchega "Replace the files in the destination?" -- Yes /
   Replace pe click kar dena. Sirf 3 files replace hongi, baaki sab
   (node_modules, .env, supabase, other components, etc.) untouched
   rahega.
3. Us folder me terminal (Git Bash / PowerShell / VS Code terminal)
   kholke:
     git add -A
     git commit -m "Add select + bulk delete to admin orders"
     git push

Bas itna hi -- push hote hi tumhari hosting (Netlify) apne aap
redeploy kar degi.

Note
-----
Database side pehle hi safe hai (returns, tracking, reviews, loyalty
wagera tables me ON DELETE CASCADE/SET NULL already set hai), isliye
koi migration run karne ki zaroorat nahi -- sirf ye 3 files replace
karni hai.
