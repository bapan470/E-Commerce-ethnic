FREE ADDRESS AUTOSUGGEST — HOW TO APPLY
========================================

What this adds
---------------
A free, no-API-key address autosuggest dropdown under the "Street address"
field, on both:
  - the Checkout page shipping address form
  - the Account > Saved Addresses form

As the shopper types 4+ characters, it queries OpenStreetMap's free
Nominatim search API (restricted to India) and shows matching addresses.
Picking one fills Street address + City + State + Pincode automatically.
No signup, no API key, no cost.

This is on top of (does not replace) the existing PIN-code -> City/State
autofill already in the checkout page.

Files changed / added
----------------------
  lib/address-suggest.ts            (NEW) - the free suggestion helper
  app/checkout/page.tsx             (MODIFIED)
  app/account/addresses/page.tsx    (MODIFIED)

How to apply
-------------
Option A (recommended) — just copy these 3 files into your local clone,
overwriting the existing app/checkout/page.tsx and
app/account/addresses/page.tsx, then:

    git add lib/address-suggest.ts app/checkout/page.tsx app/account/addresses/page.tsx
    git commit -m "Add free address autosuggest to checkout & saved addresses"
    git push

Option B — apply the included CHANGES.diff instead:

    git apply CHANGES.diff
    git add lib/address-suggest.ts
    git commit -m "Add free address autosuggest to checkout & saved addresses"
    git push

Notes
------
- No .env changes needed, no new dependencies.
- If OpenStreetMap's API is ever slow/unavailable, suggestions just don't
  show up — checkout is never blocked by it.
