REVERT — ADDRESS AUTOSUGGEST REMOVED
======================================

The free address-autosuggest feature has been removed since it wasn't
working reliably for real addresses.

What's included
-----------------
  app/checkout/page.tsx             (reverted to original — no autosuggest)
  app/account/addresses/page.tsx    (reverted to original — no autosuggest)

The original PIN-code -> City/State autofill (unrelated to the suggestion
dropdown, and already working before) is untouched and still there.

How to apply
-------------
Copy these 2 files into your local clone, overwriting the current
app/checkout/page.tsx and app/account/addresses/page.tsx, then:

    git add app/checkout/page.tsx app/account/addresses/page.tsx
    git rm lib/address-suggest.ts   (if it exists in your repo)
    git commit -m "Revert address autosuggest — unreliable for real addresses"
    git push
